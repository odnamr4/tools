# tools

Herramientas reutilizables, con instrucciones y ejemplos de uso.

## Organización

- scripts/
- docs/
- examples/

## Forma de trabajo

- Usar nombres descriptivos en minúsculas y separados por guiones.
- Documentar cada proyecto o experimento con su propio README.
- Crear un repositorio independiente cuando un proyecto tenga alcance propio.
- No guardar contraseñas, tokens ni archivos .env.
